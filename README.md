# Translucent Calendar

Web 会議をブッチしがちな、過集中気味な人のための常駐・半透明カレンダー（macOS）。

画面の隅に半透明の箱を置き、直近の予定を縦に並べて出し続けます。会議の開始が近づくと、箱が揺れて予定が明滅し、止めるまでやめません。通知センターのバナーを無意識に閉じてしまう人でも、視界の端で動き続けるものには気づけます。

## できること

- **常駐する半透明の箱**: すべてのデスクトップに表示され、移動・リサイズ・透明度の調整ができます。位置とサイズは次回起動時に復元されます。
- **直近の予定を縦に一覧**: 今日から最大30日先まで。進行中の予定は強調し、終了した予定も3時間は残します（直前の1件だけ見えていて、それより前は上にスクロール）。現在位置には線が入ります。
- **開始を揺れと明滅で通知**: 開始1分前（橙・小さな揺れ）と開始時刻（赤・大きな揺れ）の2段階。手で止めるまで続き、1分前に止めても開始時刻にもう一度始まります。
- **ワンクリックで会議に参加**: Google Meet / Microsoft Teams / Zoom / Webex の URL を予定から拾い、行の右端のボタンで開きます。
- **予定の詳細**: 行をクリックすると、場所・メモ・リンクを展開します。
- **通知する予定を選べる**: 「会議 URL のある予定のみ」「すべての予定」「通知しない」の3択に加え、予定ごとに個別のオン／オフも指定できます。
- **表示するカレンダーを選べる**: アカウントごとにチェックボックスで切り替えます。

## 必要なもの

- macOS 14 以降
- Swift のビルド環境（Xcode、または Command Line Tools だけでも可）
- macOS に登録した Google アカウント（システム設定 > インターネットアカウント）

予定は EventKit 経由で、macOS が同期しているカレンダーデータから読みます。Google の API キーや OAuth クライアントの用意は要りません。macOS のカレンダーアプリを使う必要もありません。

## インストール

```bash
git clone https://github.com/shunsukeaihara/TranslucentCalendar.git
cd TranslucentCalendar
./scripts/make_signing_cert.sh   # 初回のみ。下の「コード署名」を参照
./build.sh install
```

`./build.sh install` は、リリースビルドを作って `/Applications/TranslucentCalendar.app` に置き、起動し直します。`./build.sh` だけなら `build/` にアプリを作るだけです。

入れる先を変えたいときは `INSTALL_DIR` で指定します（例: `INSTALL_DIR=~/Applications ./build.sh install`）。

### 初回の設定

1. **Google アカウントを追加**: システム設定 > インターネットアカウント で Google を追加し、「カレンダー」をオンにします。
2. **カレンダーへのアクセスを許可**: 初回起動時にダイアログが出るので許可します。
3. **（任意）カレンダーアプリの通知を切る**: macOS のカレンダーアプリからも通知が出るようになります。不要ならシステム設定 > 通知 > カレンダー でオフにします。

## コード署名

署名の設定をしなくてもビルドと実行はできますが、**ビルドし直すたびにカレンダーへのアクセス許可を聞かれます。**

macOS はアクセス許可をアプリの署名に紐づけて覚えています。署名 ID を指定しない「アドホック署名」では、署名の中身がビルドごとのハッシュになるため、再ビルドするたびに別のアプリとして扱われます。固定の署名 ID で署名しておけば、再ビルドしても許可が引き継がれます。

### 自己署名証明書を使う（Apple ID 不要）

```bash
./scripts/make_signing_cert.sh
```

このスクリプトは次のことをします。

- `TranslucentCalendar Local Signing` という名前の自己署名コード署名証明書（有効期間10年）と秘密鍵を作ります。
- それをログインキーチェーンに取り込みます。秘密鍵は一時ディレクトリで作り、取り込み後に消します。
- すでに同名の証明書があれば何もしません。

以降、`./build.sh` はこの証明書を自動で見つけて署名に使います。初めて署名するときに「codesign がキーチェーン内のキーを使おうとしています」というダイアログが出たら、「常に許可」を選んでください。

この証明書は Apple に信頼されたものではないので、できるのは「この Mac で同じアプリだと認識させる」ことだけです。ビルドしたアプリを他の Mac に配る用途には使えません。

不要になったら、キーチェーンアクセスで `TranslucentCalendar Local Signing` の証明書と秘密鍵を削除してください。

### 自分の署名 ID を使う

Apple Development や Developer ID の証明書を持っている場合は、環境変数で指定できます。

```bash
security find-identity -v -p codesigning          # 使える署名 ID の一覧
CODESIGN_IDENTITY="Apple Development: Your Name (XXXXXXXXXX)" ./build.sh install
```

`CODESIGN_IDENTITY` を指定するとそれが最優先で使われます。指定がなく、上の自己署名証明書もなければ、アドホック署名になります。

## 使い方

| 操作 | 方法 |
|---|---|
| 移動 | 上部の日付バーをドラッグ |
| リサイズ | 箱の端や角をドラッグ |
| 予定のスクロール | ホイール／トラックパッド、または一覧をドラッグ |
| 詳細を開く・閉じる | 予定をクリック |
| 会議に参加 | 行の右端のビデオのアイコン、または詳細の「〜に参加」 |
| 設定メニュー | メニューバーのアイコン、または箱の上で右クリック |
| 通知を止める | メニューの「通知を停止」、または「参加」ボタン |

メニューからは、全体と背景の不透明度、文字サイズ、表示する期間、常に最前面に表示、位置の固定（クリックを透過）、開始の通知の対象、表示するカレンダー、ログイン時に起動、などを設定できます。「通知のデモ」で、揺れと明滅の見え方を確認できます。

揺れている最中でも、カーソルを箱の上に乗せている間は揺れが止まるので、ボタンやメニューを狙えます（明滅は続きます）。

箱を隠してしまってメニューにも辿り着けなくなったら、アプリをもう一度開けば箱が出てきます。

## 既知の問題

- **メニューバー管理アプリとの相性**: macOS 26 以降で Thaw などを併用していると、メニューバーのアイコンが表示されなかったり、絵が崩れたりすることがあります。設定は箱の右クリックメニューからすべて操作できます。
- **末尾にスペースのあるパス**: アプリを置くフォルダのパスの末尾にスペースがあると、メニューバーのアイコンが出ないことがあります。`./build.sh install` で `/Applications` に置いて使ってください。
- **Google との同期間隔**: 同期は macOS 任せなので、Google 側の変更が反映されるまで数分かかることがあります。メニューの「今すぐ更新」で同期を促せます。
- **会議リンクの検出**: 予定の URL・場所・メモに書かれたリンクから拾っています。カレンダー側がそこにリンクを入れていない予定では、参加ボタンが出ません。

## 開発メモ

- Swift Package Manager だけでビルドでき、Xcode プロジェクトはありません。`build.sh` が `.app` バンドルの組み立てと署名まで行います。
- Xcode なし（Command Line Tools のみ）でもビルドできるよう、SwiftUI のマクロ（`@State`、`@Observable` など）は使わず、状態は `ObservableObject` に持たせています。
- アプリアイコンは `swift scripts/make_icon.swift` で `Resources/AppIcon.icns` を生成しています。
- UI の文言は日本語のみです。
